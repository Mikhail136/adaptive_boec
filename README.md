# Adaptive Boec

Инженерный демонстрационный проект.

Система адаптивной приоритизации и сжатия потока информации
для военных систем связи, БПЛА и боевых машин.

## Цели проекта

- снижение перегрузки оператора;
- приоритизация сообщений;
- адаптивное управление каналом связи;
- фильтрация второстепенных данных;
- демонстрация интеллектуальной маршрутизации информации.

## Технологии

- Python
- Linux
- GitHub
- VS Code

## Структура проекта

- core/ — логика обработки
- channel/ — модель канала связи
- adapters/ — адаптеры источников данных
- experiments/ — эксперименты и тесты
